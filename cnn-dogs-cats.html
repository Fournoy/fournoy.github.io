Introduction to Convolutional Neural Network (CNN)

A Convolutional Neural Network (CNN) is a type of artificial neural network specifically designed to process images.

CNNs is used the field of computer vision and are used in many applications like image classification. Their effectiveness stems from their ability to automatically learn filters (or kernels) that detect relevant features in images.

Fundamental Concepts of CNNs

Convolutional Layers

The convolutional layer is the core of a CNN. It uses small filters (typically 3x3 or 5x5) that slide over the image to extract features taht can be lines or borders for exemple.

Activation Functions ReLu (Rectifier Linear Unit)

Activation functions ReLU will keep pixels with positive value, the negative one will be turn to 0. ReLu is import to shape correctly the input image, creating at the end, a "feature map".

Pooling Layers

Pooling reduces the dimensionality of data while preserving the most relevant information. Max pooling, for example, retains the maximum value in a given region. This reduces the number of parameters.

Fully Connected Layers

After several convolutional and pooling layers, flattened data is passed through fully connected (or dense) layers that enable the network to make final classification decisions.

Project Description

This project aims to put CNN concepts into practice by creating a model capable of automatically classifying photos of dogs and cats. It's an excellent starting point for understanding how convolutional neural networks work in practice.

Possible Improvements

Adding Supplementary Layers

The first model is a good exemple of overfitting. It memorize datas and have a hight confidence even when it's false during test phase. Now, the work is to find out how to upgrade the model. For that, we will see three different technics and see the impact on the CNN model. Using Dropout

The first technics we will see is the Dropout method. This method aim to reduce the overfitting effect by turning off randomly some input from the next layers. Dropout try to alterate the network in order to improve the training phase. Here a good illustration from pyimagesearch website. We need to precise a float number between 0 and 1, this float number will be the fraction of the network that will be « turn off ». Here, we made it with a 0.3 number.

Here the graph of loss and val_loss value, and accuracy and val_accuracy value. As you can observe, the first graph decrease throught epoch, that's a good sign explaning that our model tends towards good weights. But in the fifth epoch, val_loss encrease with a pic at the tenth epoch, despite the loss continue to decrease. We see here an overfitting. But this is due to the hight number of epoch, here we need to stop at the good moment (with EarlyStopping). The final val_loss is 0.3451 and the val_accuracy is 0.8547. This better than the first try ! But we want a more precise model. In the perfect case, the loss and val_loss need to tends towards zero. Accuracy and val_accuracy need to tends toward 1. In our case, val_accuracy and accuracy must converge in 0.9 or upper value, with a val_loss as little as possible.
As we see, the Dropout have a rate of 0.3. Now, we need to test the Dropout with a 0.5 value to see if it will change something. Here you can see the representative curve of the val_loss and loss with a Dropout of 0.5. As we see in graphs, we have a less chaotic behaviour during the overfitting. It's interesting in order to prevent overfitting more efficietly, but the parameter is maybe to hight for the CNN model used here. We need to test several different parameter to have the best parameter number for the Dropout method. With a 0.5 parameter, 50% of the input is deactivated. This hight number can be messy this small network. Let's try with 0.4 parameter for the Dropout.
