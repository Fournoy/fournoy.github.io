TL;DR

The infrastructure provide sovereign technologies and resilient application that can be used in a entire infrastructure. We using a micro-services architecture used to easily add or manipulate some micro-services. Everything is on a virtualise kubernetes, a cluster virtualised by SUSE Haverster. Due to devlopment of LLM application, we incorpore in this prototype an LLM in order to record information gathered during meetings, crisis response teams and so on, theses informations is used to create a markdown gantt diagram. About the security of the infrastructure, we using a Data Centric Security architecture and eBPF technologie to secure network and data.

Context

Due to the monopilization of some technologie by company, an entire infrastructure can be breakdown in certain case. The main objective of the hackathon is to provide an infrastructure using french technologies or european technologies. Of course, we can also use open-source technologies but with certainty of a hight european/french community.

Technic stack

  • Harvester : To create and manage virtualisation on the infrastructure
  • K3s : Create, manage and configure container
  • K9s : GUI tool in order to manage the container in the infrastructure
  • Quarkus : Used to make APIs
  • Cilium : Security and manager tool using eBPF techologie
  • Samba DC AD : Active Directory
  • Authentik The SSO technologie used to organize the various data regard the habilitation of each of these.
  • Docker : Another containerization tool for LLM used
